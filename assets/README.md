# Third-Party Assets

## VectoRaith — Farming Sim Asset Pack

The farming game uses assets from the Farming Sim Asset Pack created by VectoRaith.

- **Creator:** VectoRaith
- **Official source:** https://vectoraith.itch.io/farming-sim-asset-pack
- **Assets used:** Crop sprites and summer terrain tiles.
- **Terms:** Please refer to the creator's official asset page for the applicable license and usage restrictions.

The original asset files are not included in this repository. To run the game, download the asset pack from the official source and place the required files in the appropriate locations under `assets/vectoraith/`.

All rights to these third-party assets remain with their respective creator. Please respect the creator's license when using or distributing them.
